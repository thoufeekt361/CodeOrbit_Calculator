# 🧮 Simple Calculator Web App

A simple and responsive **Calculator Web App** built using **HTML, CSS, and JavaScript**. The application provides a clean calculator-style interface and performs basic arithmetic operations with proper handling of invalid inputs.

## 📌 Project Overview

The Simple Calculator Web App is a beginner-friendly web development project designed to perform basic mathematical calculations through an easy-to-use interface.

The calculator supports addition, subtraction, multiplication, division, modulo, and decimal calculations. It also handles invalid operations such as division by zero gracefully.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- `%` Modulo operation
- 🔢 Decimal number support
- 🧹 Clear All (`AC`) button
- ⌫ Delete (`DEL`) button
- ⚠️ Division-by-zero error handling
- ❌ Invalid input handling
- 🎨 Clean and modern user interface
- 📱 Responsive design
- 🖱️ Interactive button effects

## 🛠️ Technologies Used

- Error messages for invalid operations

## ⚙️ How It Works

1. Enter numbers using the calculator buttons.
2. Select an arithmetic operator.
3. Enter the next number.
4. Press the `=` button to calculate the result.
5. Use `AC` to clear the complete expression.
6. Use `DEL` to remove the last entered character.
7. Invalid operations such as division by zero are handled with an appropriate error message.
